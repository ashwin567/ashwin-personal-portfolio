# Ashwin Shibu — Personal Portfolio

A responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Features
- Responsive layout for desktop and mobile
- About, education, skills, projects, and contact sections
- Mobile navigation menu
- Automatically updated footer year

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a web browser.

## Before publishing
- Replace the placeholder GitHub profile link with your actual GitHub profile URL.
- Review your contact details and update anything that changes.
- Keep the skills section accurate to the technologies you are actively learning or can demonstrate.

## Technologies
- HTML5
- CSS3
- JavaScript
